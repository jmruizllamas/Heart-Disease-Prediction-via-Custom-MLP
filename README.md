# Heart-Disease-Prediction-via-Custom-MLP
This repository hosts a rigorous software engineering project aimed at predicting the presence of heart disease using a **Multilayer Perceptron (MLP)** built entirely from scratch using `NumPy`. **Key Achievement:** The custom model achieved a **Recall of 88.17%**, outperforming the Scikit-Learn library implementation (78.49%) on the same test set
